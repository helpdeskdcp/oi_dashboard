🤖 AI Auto-Trading Settings ← Manual Trading

⚠️ When enabled, a genuine signal from that engine opens a PAPER order automatically against YOUR OWN wallet -- same wallet, same ledger, and the same auto-exit rules as your manual trades. It's tagged with a Source badge ("AUTO") on the Manual Trading page so you can tell it apart from your own manual entries at a glance. Turning this off only stops NEW auto-entries -- it doesn't close anything already open.

📏 Lots, not units -- Qty below is number of LOTS, same as the Manual Trading page. Each engine can trigger across several symbols with different lot sizes (e.g. NIFTY 65, BANKNIFTY 30, SENSEX 20), so the actual order quantity = lots × that symbol's own lot size at entry time, not the raw number typed here.
Swing S/R Engine Auto-Trading
Opens an order whenever the Swing S/R Engine's own trigger fires for any symbol it's watching.
Scalp Engine Auto-Trading
Opens an order whenever the Scalp Engine's own candidate becomes tradeable. Only fires while the Scalping Engine itself is enabled (admin-controlled, /dev-settings).

Settings apply on the next genuine signal -- no restart needed.
